V1.2开发优先：用户要求减少保守测试、哈希和反复备份确认。继续真实数据批次与功能开发，按变更范围核对和回读；完整审计/恢复/上传下载放里程碑、实际交接或最终交付。本段覆盖下方旧流程中逐轮全库检查/快照的要求，保留身份与证据判断、单写入端及飞书仅CLI。

`src/save_progress.py` 保存每批状态时同时生成私有 `exports/progress-brief.md` 和 `data/progress-brief.json`：分别列出候选、资格、非电子书初查、完全未查、签约时间及本批CLI回读范围。完全未查不等于全部剩余；总体边界未知时不算全站完成率。摘要复用已保存批次与回执，不新增联网审核或备份。权利/资格有更新时先重生成售出分析，再保存进度摘要。

当前口径V1.1：售出/授权签约优先，上线不证明窗口内新售。先读exports/rights-sales-report.md、rights_records导出及对应官方证据。尚未上线的已签约记录保留；清单多行不当多合同，未知签约时间不按上线或排序推定。

明确“已获授权”的窗口前官方公告可证明该项授权至迟已存在，归窗口前披露；签署日仍空白。窗口内的公告也不能自动证明窗口内签署。电子书项目与逐卷ISBN版本分层保存，渠道发行字段不当新售、销量或全市场首发；零售站点不作授权地域。实际查询中题名内英文引号替为空格时保留原题名与实际查询，不猜改名或合并身份。

长佩渲染清单入库使用 `src/ingest_cp_rights.py --capture 私有捕获文件 --batch 唯一批次名`；资格元数据使用 `src/ingest_cp_qualification_metadata.py --capture 私有捕获文件 --batch 唯一批次名`。核对既有身份后单端写入，常规批次不重复副本模拟。清单未映射权利类型保留原文；资格记录不能投影成空媒介列，也不改变9媒介状态。详情显示非纯爱类别时保留排除边界；链接失效不否定历史授权。当前分页边界与下一固定队列以私有接续文件为准，不沿用旧聊天中的页码。

真实标题、作者与作品ID加载后仍显示的“尚未签约”是当前作品标记，应保留证据；没有标记不能推已签约。作品级签约与衍生授权、原发关系分别核验。作品别名通过 `src/feishu_work_aliases.py` 幂等建列，再完整同步回读；别名仅按同ID明确声明或其他直接身份关系保存，不自动合并跨ID记录。队列状态须查实际入库及CLI回执，旧索引初查已完成不等于售出深查完成。

私有云端若使用基础包加补充包，补充包不能单独恢复。按恢复说明下载两包并核各自SHA；`src/build_recovery_supplement.py --base 基础包 --current 补充包 --base-url 已核基础包地址 --output 新验证目录` 会拒绝不匹配基础包、核验全部文件，并生成 `combined-recovery-check.zip`。恢复使用该合并包，保留合并清单；本地完整快照另存，云端上传与云端下载校验仍分开记录。

长佩版权信息可在内置浏览器公开渲染；读取器只返回页脚时不能判整站受阻。按“改编”“海外改编”分区保存实际选中页码和行序，不复制会话、不猜API。详情首屏空标题、零值或“尚未签约”可能是加载占位；须等真实书名/作者/题材加载，不能导入占位状态或截止日后实时数值。

1. 阅读 PRD、AGENTS、STATUS、私有 exports/coverage_summary.json 和 receipts/validation.json。
2. 确认当前目录是独立项目。不要使用 ebook 配置、凭据或工作流。只有一个写入端。
3. 在新设备拉代码后，单独恢复匹配的数据快照；对 ZIP 内 manifest.json 逐文件校验 SHA256；恢复 SQLite 后跑 integrity_check 和 foreign_key_check。
4. 各设备独立登录 lark-cli，用户已指定飞书只用 CLI。真实 Base 配置不从Git推断；使用私有交接文件。未找到快照时不能凭代码声称恢复了调查。
5. 按实际变化范围检查新逻辑或故障，普通数据批次不重复全套测试。`python src/research.py export` 保存导出，对照覆盖台账续查，不重复创建。
6. 飞书增量使用 `python src/feishu_incremental.py --run 唯一批次名`，默认自动筛选相对上次已回读缓存发生变化的表；`--tables 表名,表名` 可指定范围，里程碑完整核验用 `--full`。选中表保存差异、实际写入及完整分页字段/关联回读；未变更表不请求，scope.json 明确列出范围。超过2000行继续翻页；结果不明先回读，不重发创建。
7. 更新数据、证据、缺口、状态与代码版本。完整快照和私有备份留在里程碑、交接或最终交付；普通批次不上传下载或重复哈希确认。调查达到全量边界之前，始终标记部分完成。
8. 截止日之后读取资格使用 `python src/collect_qualifications.py --batch 唯一批次名 --limit 25`，逐条审阅身份、题材和作品签约后再导入。不要直接复用旧 `jj-detail` 或 `finish_candidate_details.py` 将截止日后的实时指标混入窗口；本次资格读取器不保存实时指标或正文。查看既有 data/p1-*.json 的实际结果，不跳过尚未完成同步的批次。
9. 详情核验与商业媒介核查分开：详情采齐不表示商业调查完成。长佩DOM捕获先保存私有文件，其他写入进程退出后才导入；保持单写入端。
10. 存在 data/queued-batches.json 时逐项核对已入库和已回读状态。新增证据来源/精度字段由 `python src/feishu_evidence_fields.py` 幂等建列并回读；之后仍须运行增量同步填值、完整回读。不要将建列视为数据同步完成。
11. 作品页明确显示“被锁定或删除文章”时，保留该候选、原响应和缺口，不尝试绕过；该作品可从普通详情队列暂时隔离，继续其他作品。无法识别的空页、认证或拒绝仍暂停来源，不能仅凭解析失败断言整站不可访问。
12. 飞书写入成功但立即读回旧值时，程序有限次只读重查并留存每次结果，不重发写入；仍不一致则停止核对。书名含嵌套书名号时用官方作者链接定位边界，不能把书名尾部误作作者。
13. 作者专栏明确标为锁文、题材栏为空或“/”时，保留遮蔽原名和真实ID，类别与资格待核；不能因为纯爱筛选而丢弃，也不凭作者题材补全。明确为评论等非纯爱类别的记录另留排除边界。作者签约标记不推及全部作品。
14. 产品表有项目父记录、季/卷版本、待核与窗口外背景。使用 `python src/audit_analysis_grain.py` 核对粒度、父子关系、市场缺口和时间；原始行数不作为观察期内新增开发数，没有可比历史序列不计算增长。
15. `python src/feishu_evidence_fields.py` 也核对产品父级/季卷/来源标识/商业模式、事件与指标对应产品、指标上下界。建列后必须再增量同步和完整回读。历史报道阈值只存下界，精确值或观测日未知保留空；月份起止可能是日期不确定范围，不自动当期间指标。媒体转述与平台原始快照分层，不能直接算增长。
16. 私有云端备份以 `data/backup-destination-status.json` 和对应 Drive 回执为准，区分已上传、大小/父文件夹/私有权限回读、下载SHA校验三个状态。网络超时不等于文件不存在，不重复创建已上传文件；重新下载前通过连接器获取新文件引用，不保存临时下载令牌。没有下载校验时，不把本地ZIP校验称为云端下载通过。
17. 云端恢复包可以省去历史重复CLI响应，但必须保留全部数据库、事实证据、导出及当前批次完整回执，并附省略范围与原始完整包SHA；完整本地快照另存。恢复前读同目录RESTORE说明和包内RECOVERY_SCOPE。旧设备进程句柄不能直接在新设备恢复；先核对它已终止或确实仍活跃，再恢复调查写入。
18. 目录遮蔽题名或作者只能据同一官方作品ID的直接页面规范；保存目录原值、完整身份、显示差异证据和别名，保持原工作ID。不从近名或搜索猜字，不合并跨ID记录。签约与原发关系单独审阅；未签约不是排除依据。先完成身份导入，再用核实后的题名和作者执行媒介查询与入库断言。
19. 长佩官方详情若仅标“原创悬疑”等未明确感情分类，保留题材原文和资格待核；只有明确言情/百合等才记本项目排除。没有签约标记不推已签约或未签约；作品级签约、原发与衍生售出分别核实。
20. 历史目录可用 `python src/collect_jj_directory_chain.py --from-capture 已存官方目录文件 --pages 本批页数 --partition 分区名 --prefix 文件名前缀` 接续；只沿响应中的下一页，筛选改变/认证/空页即停源。新年份须先通过内置浏览器真实选择年份和排序，保存公开入口后用 `--include-seed` 采入口本页；页面参数0按首屏第1页记账。目录仅发现候选，各媒介保持未调查，不当原发或售出证明；不从当前分区页数推全站分母。
21. 长佩下一资格队列用 `python src/prepare_cp_qualification_queue.py --output data/下一批候选.json --limit 25` 生成，遍历所有 `cp-rights*-capture.json` 的改编/海外改编，不能只读取第一份捕获文件。前10页完成不表示后31页完成；队列保存全部未核数、来源捕获文件与页内行序，实际读取后才计完成。
