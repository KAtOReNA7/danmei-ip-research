# 数据字典与统计口径

SQLite `src/schema.sql` 是字段结构来源。每个表均导出 UTF-8 CSV 和 JSONL；CSV 空白表示缺值，JSONL null 保留缺失语义，显示的真实 0 不删除。

| 表 | 粒度和唯一性 | 注意 |
|---|---|---|
| works | 当前为平台来源记录；platform+source_id 唯一 | 跨站、迁站、重发未核之前，不将记录数称为去重原著总量；题材、原发/签约均须证据 |
| products | 产品或发行版本；内部键稳定生成 | source_id 只存真实ID；内部键不是平台ID；parent_id 支持季/版本归属 |
| product_works | 产品×原著关联 | 多对多；整体收入不向每部作品重复分配 |
| events | 产品×事件类型×日期 | 公告、播出安排、实际发生区分；window_role 标明窗口内或背景 |
| observations | 对象×指标×证据 | raw_value 保留显示原文；value 是解析显示数而非精确销量；缺值有 missing_reason |
| evidence | URL+必要元数据+采集时间的证据快照 | 本地文件及 SHA256；索引/检索审计不是被引事实本身 |
| coverage | 目录分区页或作品×媒介任务 | query_scope、gap、last_run 记录局部核查范围 |
| check_history | 作品×媒介×查询范围×证据 | 追加核查审计，coverage 保持最新摘要 |
| source_matrix | 媒介×来源 | 事件、当前值、历史值和访问条件分别标记 |
| exclusions | 排除案例 | 纸书及混售赠品不得作为周边收入 |

媒介：电子书、有声书、广播剧、漫画、动画、影视短剧、游戏、官方周边联名、舞台线下。

作品媒介状态：未调查、已调查未发现、发现待核、已确认、访问受阻、不适用。目录任务另用已采集/访问受阻。已确认可以确认产品存在或公告，并不自动证明窗口内真实运营、销售或可售权利。

可信状态：官方直接证据、可核验转引、未核实线索、来源冲突。纳入状态为已确认/待核，作品的原发、签约及各媒介权利分别核验。

时间：事件时间、来源发布时间、指标对应期间、采集时间分别存储；采集时间有时区。目录发表时间仅作平台显示字段，重发须另核。搜索缓存日期不是指标观测日期。无法精确定位历史值时只存线索，不制造时间序列。

统计：候选记录数=count(works)；确认纳入数按 inclusion_status 过滤，但跨站版本去重未完成时仍不称行业原著总量。产品按 id、父项目按 coalesce(parent_id,id) 去重；一个联名的周边和线下维度不双计项目。窗口事件限定事件日期及 window_role；公告与执行不能混计。确认行业统计还须连接已确认作品。平台积分、人气、播放、收藏和销售分开；同对象/指标/单位/币种/期间/口径才能比较。2026未满全年，不同比全年。

飞书采用中文前台字段；覆盖台账将9媒介转为一作品一行，保留全部状态，没有截断为试采12部。CLI每页最多2000行，增量同步继续 offset 翻页直到 has_more=false；逐字段及关联回读核验。后台键和校验字段隐藏于默认视图，原始完整数据保留本地。

详情证据计数使用非空 signing_evidence 字段，包含签约未知的作品详情快照，不能把该计数称为签约作品数。作品原发/签约确认只依据 inclusion_status 和 inclusion_basis。长佩“人阅读”保留原名，不自动解释为购买人数；“万”保留显示精度，不假称精确人数。作品简介栏日期只存证据，不直接当首次发表日。

最新目录入口使用“最新发表”排序，当前已建目录明显集中于近期作品，不具有全行业年龄或开发结构代表性。非电子书索引初查仅表示实际执行过注明的查询；未穷尽站内、海外译名与历史下架范围，不能解释为从未开发。

数字电子书项目行与卷级版本用 parent_id 连接；同一电子版ISBN作为版本去重依据，平台真实商品ID仍单列保存。一个项目的8卷不是8个IP，父项目行不得再与卷行相加计产品开发量。来源只有PDT/PST日历日期而无时刻时，events.event_time/time_end保存可能的北京时间起止日期，time_precision明确为日期范围，事实描述保留来源日期及时区；该范围不表示活动持续两天。截止日后核验的历史发行日期与当前价格、促销、馆藏数分开，后者不回填截止日。
# 权利销售主线 V1.1

rights_records是一条有来源的已售出/已授权签约披露，不是产品，也不自动等于独立合同。保留真实作品键、权利类型原文、媒介、地域原文、语言、授权方/受让方/代理方、签约时间原文/区间/精度、官宣时间、窗口归属、售出证据状态、交易键、费用/币种、URL/定位/证据与缺口。未知主体、金额、交易键、语言、日期留空。

晋江成功签约清单的空日期不继承相邻行。2026-11跨截止日，单列待核；上线时间、采集时间和官宣时间不代替签约发生时间。按披露行、去重作品与权利类型分别统计，独立交易身份不明不报交易数。纯爱分类披露范围与资格已确认子集分开。音乐/综艺保留原文而不强行映射已有9媒介。
