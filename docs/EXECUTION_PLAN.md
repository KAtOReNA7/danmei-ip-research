# 执行阶段

V1.1优先级：先核官方成功签约/权利销售与历史披露，逐条补售出时间、地域/语言、受让方、授权范围和交易身份，再补上线及表现。原固定候选队列继续保留，但泛搜索不当售出核验完成。2026-11月精度跨截止日，单列待核；空日期不继承相邻行。

P0：冻结口径，实测目录、分页、分类、榜单、作者和签约入口；9 类媒介核验事件/当前/历史可得性；两站各至少 6 部真实分层试采，记录未满足的层。

P1：可验证目录按页批次推进，保存查询条件、首尾、总数显示、失败、游标和重访边界；对每部逐媒介调查。样本、榜单及搜索发现均不能成为总体分母。

P2：身份与版本复核；优先补签约发生时间、权利范围、地域／语言、受让方及首次／续约／追加关系。分别展示窗口内确认签约、已签约时间待核、窗口前签约的执行背景；仅上线线索不进入售出确认数。之后整理执行事件和真实可比快照；按有证据范围分析，不能外推行业。

P3：独立飞书目标及可用连接明确后验证容量/权限，dry-run、去重写入、完整回读；本地数据、证据、报告、覆盖与快照封存。

阶段无需审批；局部访问受阻继续其他独立来源；全量不可证明时保持部分完成。
